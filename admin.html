🧠 Bot Brains

Choose which AI providers power the bots, in failover order. Keys are stored server-side in rooms/config.php and never sent to browsers. If every provider fails, bots fall back to the built-in offline line pack.

⏱️ Bot pacing

How long each bot "thinks" and how long its answer stays on the card before the game moves on. Raise it so humans can read every move; 0 = instant (chaotic). The slider goes to 120s — for slower tables, type any value up to 600s in the box.

Providers

Cloud providers join the chain only when a key is set. Local servers (Ollama, llama.cpp, LM Studio) are tried with a sub-second timeout and skipped when not running. Order = failover order.

Custom providers

Any OpenAI-compatible endpoint works: another box on your LAN, a proxy, a different service.
